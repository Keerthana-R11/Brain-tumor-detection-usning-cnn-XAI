# Brain-Tumor-Detection-usning-CNN-XAI

## 📌 Project Overview
This project focuses on detecting brain tumors from MRI images using Convolutional Neural Networks(CNN).  
To improve transparency and trust, Explainable AI (XAI) techniques such as Grad-CAM are used to visualize the regions influencing the model’s prediction.

## 🗂️ Dataset
- Brain MRI image dataset (Kaggle)
- Image categories:
  - pituitary
  - meningioma
  - Glioma
  - No Tumor
- Preprocessed images:
  - Resized to uniform dimensions
  - Normalized pixel values
  - Data augmentation applied (rotation, flipping, etc.)

    
## 📊 Results
- Achieved high classification accuracy on test dataset  
- Grad-CAM heatmaps clearly highlight tumor regions  
- Model demonstrates strong potential for assisting medical professionals
